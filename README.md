# 知乎 CLI（ZhihuViewer）

终端里的知乎：推荐流卡片式浏览 + 展开看全文 + 终端内直接查看图片。

在 **Ghostty**（或任何支持 Kitty 图片协议的终端）中运行效果最佳：点击图片的展开按钮，
图片会以内联方式直接渲染在终端里，随内容一起滚动。

## 功能

- **推荐流**：像网页一样无限滚动，滚动到底部自动加载下一页，启动时会自动补足内容保证可滚动
- **顶栏标签页**：`推荐` / `热榜` / `历史` 一键切换（顶栏可点，也可用 `,`/`.` 循环）；
  热榜卡片左上角显示排序号；用户名靠右对齐
- **浏览历史**：本地记录浏览过的回答 / 问题，在「历史」页按问题分组展示，可重新打开或跳浏览器
- **卡片式列表**：每条内容一张卡片（回答 / 文章 / 视频 / 提问 / 想法），显示
  类型徽标、标题、摘要、作者、赞同、评论、时间、图片数量
- **固定标题栏**：展开回答后顶部固定显示 问题 / 作者 / 赞 / 链接，
  正文区域独立滚动；**Ctrl+点击链接**在浏览器打开；回答页 `Q` 按钮可进入问题页
- **问题页**：可加载的回答卡片列表；顶栏尾端 `▼` 按钮可展开/收起问题详情
- **展开全文**：按 Enter 进入正文，不同 HTML 元素用不同颜色 / 加粗 / 背景色渲染：
  - 标题：`h1` 亮青 / `h2` 紫 / `h3` 绿，粗体
  - 引用（blockquote）：斜体 + 深蓝**整块背景** + 左侧蓝色竖线
  - 代码（pre）：**语义着色**（关键字 / 字符串 / 注释 / 数字 / 函数）+ 深色整块背景
    （inline code 灰色底）；代码块右上角有 **复制** 按钮（可一键拷贝到剪切板），
    并显示检测到的代码语言
  - 链接：蓝色下划线，点击 / Ctrl+点击 打开；每个 URL 前有一行「打开链接」小按钮
  - 列表：彩色项目符号 / 序号
  - 表格：框线对齐（按列宽自动排版，CJK 宽度感知）；**过宽的表格**自动收起，
    上方保留单行「展开表格」按钮，点击后弹窗完整查看（`hjkl`/方向键 移动、
    `空格` 翻页）
- **公式**：LaTeX 公式转 Unicode 渲染——行内公式保持单行随段落流动；
  行间公式以 **utftex** CLI 为准渲染为多行排版块并**居中显示**，
  utftex 未安装时用内置转换器兜底；知乎行间公式的 SVG 图片默认隐藏
  （在 `~/.config/zhihu-viewer/config.json` 中设 `show_math_svg: true` 可展示）
- **图片内嵌与放大**：正文图片默认折叠为「图片 N」按钮；第一次点击后按比例内嵌
  显示（最大 64 列 × 18 行），图下显示图注或格式 / 尺寸 / 文件大小，按钮变为
  「放大」并可进入查看器（Kitty 图片协议）：
  `+`/`-` 缩放、`hjkl`/方向键 平移、`,`/`.` 在当前回答内切换图片、`o` 浏览器打开、
  `Esc` 返回；`i` 一键查看回答全部图片；展开后的按钮区右侧有 **复制图片** 按钮
  （经 wl-copy/xclip 复制图片到剪切板，无工具时回退为复制图片链接）
- **光标模式**：`i` 进入，`hjkl` 在可点击目标（图片 / 链接 / 按钮）间移动，`Enter` 打开
- **选择模式**：`v` 切换，用鼠标拖选文本，`Ctrl+Shift+C` 复制（底栏 `|NORMAL| / |CURSOR| / |VISUAL|` 徽标显示当前模式）
- **搜索**：`Ctrl+S` 弹出搜索框，搜索回答 / 问题（结果列表可滚动加载更多）
- **打开指定链接**：`Ctrl+O` 粘贴链接直接打开；也可 `zhihuviewer <url>` 命令行直达
- **页内搜索**：正文 / 问题页按 `/`，支持正则，`h`/`l` 上一个/下一个
- **视频**：视频条目提供「[播放视频]」按钮跳转浏览器播放
- **登录**：自动打开浏览器登录，自动从浏览器读取 Cookie（Firefox / Chrome 系），
  失败自动降级为手动粘贴 Cookie
- **设置（命令面板）**：`Ctrl+P` 打开；可切换主题、默认展开图片、自动刷新推荐、
  浏览历史开关与缓存位置、清空历史、正文底部「尾端按钮」（在浏览器中打开 /
  下一个回答 / 隐藏）
- **滚动**：鼠标滚轮 / 触控板、方向键、`j`/`k`、PageUp/PageDown、Home/End 全部即时响应
- **加载动画**：加载时底栏左侧显示小型 spinner（如 `⠋ 加载中…`）
- **缓存**：图片下载缓存存放在 `/tmp/zhihuviewer/img/`（可在 `config.json` 的
  `cache_dir` 中自定义缓存根目录）；浏览历史默认在 `/tmp/zhihuviewer/history.json`
- **崩溃日志**：异常 / 崩溃自动记录到 `log/error.log`（含时间戳与完整堆栈）

## 环境要求

- Python **3.10+**
- 终端：**Ghostty / kitty** 等支持 **Kitty 图片协议** 的终端（图片内嵌显示）；
  其他终端图片按钮会自动改用系统默认看图程序打开
- 可选：**Nerd Font**（推荐 JetBrainsMono Nerd Font，用于图标与状态徽标）
- 可选：**utftex** CLI（`/usr/local/bin/utftex`，行间公式排版）；未安装时用内置转换器兜底

## 安装

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
```

公式渲染可选依赖 [utftex](https://github.com/seddonm1/utftex)（CLI 工具，
放在 `PATH` 中即可被自动检测）；未安装时内置转换器仍可显示公式。

## 使用

```bash
.venv/bin/zhihuviewer            # 启动（首次会自动登录）
.venv/bin/zhihuviewer --login    # 强制重新登录
.venv/bin/zhihuviewer --cookies "d_c0=xxx; z_c0=yyy"   # 直接提供 Cookie
.venv/bin/zhihuviewer "https://www.zhihu.com/question/123/answer/456"  # 直接打开某个链接
```

任意页面按 `Ctrl+O` 会弹出输入框，粘贴知乎链接即可打开该页面
（支持 question / answer / zhuanlan 专栏 / zvideo）；按 `Ctrl+S` 弹出
搜索框，输入关键词搜索回答 / 问题（结果列表与推荐流同样可滚动加载更多）。

### 按键

推荐流：

| 按键 | 功能 |
|------|------|
| `j` / `k` / `↑` / `↓` | 选择卡片 |
| `Enter` / 鼠标点击 | 展开卡片 |
| `,` / `.` | 上一个 / 下一个标签页（推荐 / 热榜 / 历史） |
| `r` | 刷新 |
| `o` | 在浏览器中打开 |
| `g` / `G` | 顶部 / 底部 |
| `q` / `Ctrl+C` | 退出 |

正文页：

| 按键 | 功能 |
|------|------|
| `Esc` / `q` | 返回 |
| `j` / `k` / `空格` | 滚动 |
| `n` / `N`（Shift+n） | 下一个 / 上一个回答（同一问题下切换，自动处理首尾边界） |
| `c` | 弹出该回答的评论页（滚动到底自动加载更多） |
| `o` | 在浏览器打开原文 |
| `i` | 光标模式（hjkl 移动，Enter 打开目标） |
| `a` | 全部图片查看 |
| `/` | 页内正则搜索（`h` / `l` 上一个 / 下一个） |
| `v` | 选择模式：用鼠标拖选文本，`Ctrl+Shift+C` 复制，再按 `v` 退出 |

正文中的**链接**以下划线显示，鼠标点击即可在浏览器中打开；标题栏的链接用 `Ctrl+点击` 打开。
滚动到回答底部时会弹出小提示（`n` 下一个回答 · `N` 上一个 · `c` 评论）。

### 登录说明

1. 自动扫描本机浏览器（Firefox 优先，Chrome/Chromium/Edge/Brave 会尝试解密）读取知乎 Cookie
2. 找不到时自动用系统浏览器打开 `zhihu.com/signin`，等待登录（最多 90 秒，期间每 2 秒重试）
3. 仍失败则提示手动粘贴 Cookie（浏览器开发者工具中复制 `zhihu.com` 的 Cookie 字符串）

Cookie 保存在 `~/.config/zhihu-viewer/cookies.json`；旧的 `cookies.txt`（Netscape 格式）也兼容。

## 图片说明

图片通过 **Kitty 图片协议** 渲染（Ghostty 原生支持）。启动时会自动探测终端；
若终端不支持（如非 Ghostty / kitty），点击图片按钮会自动**下载并用系统默认看图
程序打开**（`xdg-open`），无需手动保存。

正文图片默认折叠；支持图片协议时第一次点击内嵌展开，再点击「放大」进入查看器；
展开后可点击「折叠图片」恢复按钮状态；不支持时点击「图片 N」直接通过系统看图
程序打开。查看器按键：
`+`/`-` 缩放、`hjkl`/方向键 平移、`,`/`.` 在当前回答内切换、`o` 浏览器打开、
`Esc` 返回；`i` 一键查看回答全部图片。

## 项目结构

```
zhihu_cli/
├── __main__.py    # 入口：登录检测、终端探测、启动 App
├── config.py      # 用户配置（~/.config/zhihu-viewer/config.json）
├── history.py     # 本地浏览历史
├── net.py         # 知乎 API（推荐流 / 热榜 / 搜索 / 评论 / 登录 / Cookie）
├── htmlparse.py   # HTML -> 带样式的 rich Text（含公式 / 图片 / 表格 / 链接 / 代码着色）
├── mathtex.py     # LaTeX -> Unicode 转换器（utftex CLI + 内置兜底）
├── kitty.py       # Kitty 图片协议：探测 / 传输 / 占位符 / 删除
├── styles.tcss    # 主题样式
└── ui/            # Textual 界面（按页面 / 组件拆分）
    ├── app.py         # 应用壳：主题 / 全局按键 / 设置命令
    ├── widgets.py     # 通用控件与辅助函数
    ├── feed.py        # 推荐流 / 热榜 / 历史、搜索结果列表
    ├── question.py    # 问题页
    ├── content.py     # 正文页
    ├── image.py       # 图片内嵌与查看器
    ├── comments.py    # 评论弹窗
    ├── modals.py      # 搜索 / 表格 / 链接输入弹窗
    ├── constants.py   # 图标 / 颜色 / 主题常量
    └── __init__.py    # 对外导出
```
