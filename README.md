# 小红书 CLI（XHSViewer）

终端里的小红书：推荐流卡片式浏览 + 图文笔记内嵌看图。基于
[xhs CLI](https://github.com/jackwener/xiaohongshu-cli)（逆向 API）取数，
界面以 **小红书红 `#FF2442`** 为主题色。

在 **Ghostty**（或任何支持 Kitty 图片协议的终端）中运行效果最佳：图集第一张
图片会**自动内嵌**显示在正文里，`‹`/`›` 直接翻页，点「放大」进入全屏查看器。

## 功能

- **推荐流**：像 App 一样无限滚动，滚动到底部自动加载下一页，启动时会自动
  补足内容保证可滚动（`xhs feed` 无游标，按笔记 ID 去重续拉）
- **顶栏标签页**：`推荐` / `热门` / `历史` 一键切换（顶栏可点，也可用 `,`/`.` 循环）；
  热门卡片左上角显示排序号；用户名靠右对齐
- **浏览历史**：本地记录浏览过的笔记，在「历史」页按**作者**分组展示，可重新打开
  或跳浏览器
- **卡片式列表**：每条内容一张卡片（图文 / 视频），显示类型徽标、标题、摘要、
  作者、点赞、收藏、评论、时间、图片数量
- **列表封面图**：命令面板（`Ctrl+P`）中开关列表卡片内的 **3:4 封面图**
  （`contain` 适配，letterbox 留边）；封面左侧、文字右侧
- **宫格视图**：命令面板（`Ctrl+P`）中在列表 / 宫格之间切换。宫格中每张卡片
  变成一格：上方 3:4 封面图，下方标题 / 作者 / 点赞；封面右下角有图片数量
  角标（`n`，黑底白字、无括号；推荐流卡片默认没有数量，聚焦格子时后台补拉
  一次详情）。**列数随终端宽度自适应**，单元格大小可在 `Ctrl+P` 中分档调整
  （小 / 中 / 大 / 特大，默认特大）
- **图文优先的笔记页**（Photo first，可在 `Ctrl+P` 中切换为文字优先）：
  - **图集**：默认排在正文之前，第一张图片自动内嵌显示，`‹ n/N ›` 翻页，
    `放大` 进入查看器，`🗎` 一键复制当前图片到剪切板
  - **正文**：`#话题#` 红色高亮、`@用户` 浅红高亮、链接下划线可点击
  - **话题按钮**：点击任一 `#话题` 直接搜索该话题
  - **视频笔记**：显示时长并在浏览器播放
  - 顺序设置：命令面板 →「笔记图文顺序：图片优先 / 文字优先」，切换后当前
    笔记立即重排
- **固定标题栏**：展开笔记后顶部固定显示 标题 / 作者 / ♥ / ★ / 评论 / 时间 /
  IP / 链接；**Ctrl+点击**在浏览器打开
- **切换笔记**：`n` / `N` 在当前列表（推荐 / 热门 / 搜索）内切换上一条 / 下一条
- **评论**：`c` 弹出评论页（含楼中楼回复、点赞数、IP 属地，滚动到底自动加载更多）
- **搜索**：`Ctrl+S` 弹出搜索框，搜索笔记；结果列表可滚动分页加载
- **打开指定链接**：`Ctrl+O` 粘贴链接直接打开；也可 `xhsviewer <url>` 命令行直达
  （支持 `explore` / `discovery/item` 链接、`xhslink.com` 短链与笔记 ID）
- **页内搜索**：笔记页按 `/`，支持正则，`h`/`l` 上一个/下一个
- **光标模式**：`i` 进入，`hjkl` 在可点击目标（图集控件 / 链接 / 话题 / 按钮）间移动，
  `Enter` 打开
- **选择模式**：`v` 切换，用鼠标拖选文本，`Ctrl+Shift+C` 复制（底栏
  `|NORMAL| / |CURSOR| / |VISUAL|` 徽标显示当前模式）
- **设置（命令面板）**：`Ctrl+P` 打开；可切换主题、图集自动加载、列表卡片图片、
  列表 / 宫格布局、宫格图片大小（小 / 中 / 大 / 特大）、笔记图文顺序（图片优先 /
  文字优先）、自动刷新推荐、浏览历史开关与缓存位置、清空历史、正文底部
  「尾端按钮」（在浏览器中打开 / 下一条笔记 / 隐藏）
- **滚动**：鼠标滚轮 / 触控板、方向键、`j`/`k`、PageUp/PageDown、Home/End 全部即时响应
- **加载动画**：加载时底栏左侧显示小型 spinner（如 `⠋ 加载中…`）
- **缓存**：图片下载缓存存放在 `/tmp/xhsviewer/img/`（可在 `config.json` 的
  `cache_dir` 中自定义缓存根目录）；浏览历史默认在 `/tmp/xhsviewer/history.json`
- **崩溃日志**：异常 / 崩溃自动记录到 `log/error.log`（含时间戳与完整堆栈）

## 环境要求

- Python **3.10+**
- 已安装并登录 **`xhs` CLI**（本项目通过它访问小红书 API）：
  ```bash
  pipx install xiaohongshu-cli   # 或 uv tool install xiaohongshu-cli
  xhs login                      # 从浏览器读取 Cookie；失败可 xhs login --qrcode
  xhs status                     # 确认已登录
  ```
- 终端：**Ghostty / kitty** 等支持 **Kitty 图片协议** 的终端（图片内嵌显示）；
  其他终端图片按钮会自动改用系统默认看图程序打开
- 可选：**Nerd Font**（推荐 JetBrainsMono Nerd Font，用于图标与状态徽标）

## 安装

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
```

## 使用

```bash
.venv/bin/xhsviewer            # 启动（未登录时会自动调用 xhs login）
.venv/bin/xhsviewer --login    # 强制重新登录
.venv/bin/xhsviewer "https://www.xiaohongshu.com/explore/xxxxxxxx"  # 直接打开笔记
```

任意页面按 `Ctrl+O` 会弹出输入框，粘贴小红书笔记链接即可打开；
按 `Ctrl+S` 弹出搜索框，输入关键词搜索笔记（结果列表可滚动加载更多）。

### 按键

列表页：

| 按键 | 功能 |
|------|------|
| `j` / `k` / `↑` / `↓` | 选择卡片 |
| `Enter` / 鼠标点击 | 展开笔记 |
| `,` / `.` | 上一个 / 下一个标签页（推荐 / 热门 / 历史） |
| `r` | 刷新 |
| `o` | 在浏览器中打开 |
| `g` / `G` | 顶部 / 底部 |
| `q` / `Ctrl+C` | 退出 |

笔记页：

| 按键 | 功能 |
|------|------|
| `Esc` / `q` | 返回 |
| `j` / `k` / `空格` | 滚动 |
| `n` / `N`（Shift+n） | 下一条 / 上一条笔记（当前列表内切换） |
| `,` / `.` / `[` / `]` | 图集上一张 / 下一张 |
| `h` / `l` | 图集上一张 / 下一张（光标模式下为移动光标） |
| `a` | 全屏查看全部图片 |
| `c` | 弹出该笔记的评论页（滚动到底自动加载更多） |
| `o` | 在浏览器打开原文 |
| `i` | 光标模式（hjkl 移动，Enter 打开目标） |
| `/` | 页内正则搜索（`h` / `l` 上一个 / 下一个） |
| `v` | 选择模式：用鼠标拖选文本，`Ctrl+Shift+C` 复制，再按 `v` 退出 |

### 登录说明

登录完全交给 `xhs` CLI 管理：

1. 未登录时本程序会自动运行 `xhs login`，从本机浏览器读取小红书 Cookie
2. 浏览器读取失败时自动改用 `xhs login --qrcode`，用小红书 App 扫码
3. 仍然失败时可手动运行 `xhs login --qrcode` 完成登录
4. `xhs status` 可随时检查登录状态
5. 若提示 **「需要完成小红书安全验证」**：这不是登录过期（`xhs status` 仍显示
   已登录），而是小红书风控要求验证码。程序会弹出对话框，点击
   **「在浏览器中验证」**（或按 `o`）即跳转 `xiaohongshu.com`，在浏览器里完成
   一次验证后回来重试即可；对话框内也有「关闭」单行按钮。程序已限制
   「宫格数量补拉」的请求频率以减少触发

## 图片说明

图片通过 **Kitty 图片协议** 渲染（Ghostty 原生支持）。启动时会自动探测终端；
若终端不支持（如非 Ghostty / kitty），**列表封面图与宫格视图自动禁用**
（命令面板中的对应选项会提示不可用），图集保持折叠：点击图片按钮即**下载并用
系统默认看图程序打开**（`xdg-open`），无需手动保存；`a` 只打开当前这一张。

笔记图集默认自动内嵌第一张；`‹`/`›`（或 `,`/`.`、`h`/`l`、`[`/`]`）切换，
`放大` 进入查看器。查看器按键：
`+`/`-` 缩放、`hjkl`/方向键 平移、`,`/`.` 切换、`o` 浏览器打开、`Esc` 返回；
`a` 一键查看当前笔记全部图片。

## 项目结构

```
xhs_cli/
├── __main__.py    # 入口：登录检测、终端探测、启动 App
├── config.py      # 用户配置（~/.config/xhs-viewer/config.json）
├── history.py     # 本地浏览历史（按作者分组）
├── net.py         # xhs CLI 封装：推荐流 / 热门 / 搜索 / 笔记 / 评论 / 图片缓存
├── htmlparse.py   # （遗留）知乎 HTML 解析，未参与小红书渲染
├── mathtex.py     # （遗留）LaTeX -> Unicode 转换器
├── kitty.py       # Kitty 图片协议：探测 / 传输 / 占位符 / 删除
├── styles.tcss    # 红色主题样式
└── ui/            # Textual 界面（按页面 / 组件拆分）
    ├── app.py         # 应用壳：主题 / 全局按键 / 设置命令
    ├── widgets.py     # 通用控件与辅助函数（卡片 / 顶栏 / 笔记头 / 历史）
    ├── feed.py        # 推荐流 / 热门 / 历史、搜索结果列表
    ├── content.py     # 笔记正文页（图集 / 话题 / 视频 / 评论入口）
    ├── image.py       # 图集内嵌、全屏查看器、剪贴板复制
    ├── comments.py    # 评论弹窗（含回复）
    ├── modals.py      # 搜索 / 表格 / 链接输入弹窗
    ├── constants.py   # 图标 / 颜色 / 主题常量
    └── __init__.py    # 对外导出
```

## 从知乎版迁移

本项目原为知乎 CLI（ZhihuViewer）。现已整体替换为小红书后端（`xhs` CLI），
旧版知乎 API / Cookie 登录相关代码已移除；`htmlparse.py`、`mathtex.py` 与
`tests/` 作为遗留代码保留，未参与小红书渲染。
